# Security Policy

Revyrie Commerce takes the security of our clients' stores and code seriously.
Most of our repositories are private and shared only with the people working on
the project.

## Reporting a concern

If you find a security issue, an exposed credential, or access that should not
be there, please report it privately to your project manager or to
[support@revyrie.com](mailto:support@revyrie.com). Include the repository, a
description of the issue, and steps to reproduce it where possible.

Please do not post the details in a public issue, a pull request, or a comment.

## Handling credentials

- Never commit API keys, tokens, passwords, or customer data to a repository.
- If a credential is committed by mistake, report it right away so it can be
  rotated. Deleting the commit is not enough.

## What to expect

We will review your report and follow up using the contact details you provide.
We are a small team and do not operate a formal response timeline or bug bounty
program.
